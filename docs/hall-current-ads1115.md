# PZCT-DC63 + ADS1115: измерение DC-тока

Прошивка v0.15.9+ поддерживает датчик тока Холла **PZCT-DC63** через 16-битный АЦП **ADS1115** на общей I²C-шине ESP32 (`GPIO21 = SDA`, `GPIO22 = SCL`).

## Используемый датчик: PZCT-DC63-300A

В проекте используется исполнение **PZCT-DC63-300A**. По маркировке датчика и предоставленным электрическим данным:

- номинальный ток: **±300 A**;
- диапазон измерения: **±330 A**;
- питание датчика: **+5 V DC (±5%)**;
- выход при `Vcc = 5 V`: **2.5 V ± 2 V**, то есть примерно **0.5…4.5 V**;
- нулевой уровень: **2.5 V ±10 mV** при `Vcc = 5 V`;
- нагрузка выхода: **≥10 kΩ**;
- линейность: **≤0.5% FS**;
- общая точность: **±1% FS при 25 °C**;
- потребление: **≤20 mA**;
- время отклика: **<10 µs**;
- полоса: **DC…30 kHz**.

Из диапазона `2.5 V ±2 V` для ±300 A получается номинальная чувствительность:

`2.0 V / 300 A ≈ 6.667 mV/A`.

Это совпадает с пресетом **300 A** в Web UI. Точная чувствительность конкретного экземпляра определяется двухточечной калибровкой.

Стрелка на корпусе задаёт положительное направление измеряемого тока. Если фактический знак оказывается обратным, можно развернуть датчик/проводник либо включить инверсию направления в Web UI.

## Питание ADS1115 и PZCT-DC63

В используемой сборке **и PZCT-DC63-300A, и ADS1115 питаются от 5 V**.

ADS1115 при этом подключён к ESP32, логические уровни которого — **3.3 V**. Поэтому линии I²C `SDA` и `SCL` нельзя подтягивать к 5 V напрямую.

Рекомендуемый вариант — двунаправленный I²C level shifter:

- сторона `LV` → `3V3` ESP32;
- сторона `HV` → `5V`;
- `SDA/SCL` ESP32 → LV1/LV2;
- `SDA/SCL` ADS1115 → HV1/HV2;
- земля общая.

Если конкретный модуль ADS1115 позволяет отключить его встроенные pull-up резисторы и вся I²C-шина гарантированно подтянута только к 3.3 V, level shifter может быть не нужен. Для универсальной схемы проекта рекомендуется level shifter.

> Не подключайте 5-вольтовые `SDA/SCL` непосредственно к GPIO ESP32.

## Подключение

На разных ESP32 DevKit GPIO могут быть подписаны по-разному. **Главный ориентир — номер GPIO**, а `D21`, `SDA`, `IO21` и т. п. — варианты шелкографии.

| ESP32 DevKit | GPIO | Маркировка на плате | Куда подключать |
|---|---:|---|---|
| `5V / VIN` | — | `5V` / `VIN` | ADS1115 `VDD` + PZCT-DC63 `VCC` + HV level shifter |
| `3V3` | — | `3V3` / `3.3V` | LV-питание I²C level shifter |
| SDA | **21** | `SDA` / `D21` / `IO21` / `21` | level shifter LV → ADS1115 `SDA` на HV |
| SCL | **22** | `SCL` / `D22` / `IO22` / `22` | level shifter LV → ADS1115 `SCL` на HV |
| GND | — | `GND` | общий GND ESP32 / ADS1115 / PZCT / level shifter |
| — | — | — | PZCT `OUT` → ADS1115 `A0` (либо A1/A2/A3) |

Для типового ADS1115 с выводами `VDD, GND, SCL, SDA, ADDR, ALRT, A0…A3`:

| Вывод ADS1115 | Подключение |
|---|---|
| `VDD` | `5V / VIN` ESP32 |
| `GND` | общий `GND` |
| `SCL` | к GPIO22 через I²C level shifter |
| `SDA` | к GPIO21 через I²C level shifter |
| `ADDR` | `GND` для адреса `0x48` |
| `ALRT` | не подключать — прошивка его не использует |
| `A0` | `OUT` PZCT-DC63-300A |
| `A1…A3` | свободны либо могут быть выбраны вместо A0 в Web UI |

```text
ESP32 DevKit             I2C level shifter              ADS1115              PZCT-DC63-300A
-----------              -----------------              -------              ---------------
3V3 -------------------> LV
5V / VIN --------------> HV
5V / VIN ---------------------------------------------> VDD
5V / VIN ---------------------------------------------------------------> VCC
GND -------------------- GND --------------------------> GND ------------> GND
GPIO21 / SDA ----------> LV1        HV1 --------------> SDA
GPIO22 / SCL ----------> LV2        HV2 --------------> SCL
                                                       ADDR ---> GND
                                                       ALRT     NC
                                                       A0 <------------- OUT
```

ADS1115 в прошивке работает с PGA `±6.144 V`. При питании ADS1115 от 5 V сигнал PZCT около **0.5…4.5 V** можно подавать на `A0` напрямую, без делителя.

## Проводник через датчик

Через окно PZCT-DC63 пропускается **только один проводник** измеряемой DC-линии. Если пропустить одновременно плюс и минус одной цепи, их магнитные поля компенсируются и датчик покажет почти ноль.

Направление тока зависит от ориентации проводника относительно стрелки на корпусе. Если знак получается обратным, можно либо развернуть датчик/проводник, либо включить `инвертировать направление` в Web UI.

## Настройка в Web UI

Для PZCT-DC63-300A:

1. включите датчик;
2. оставьте адрес `Авто 0x48…0x4B` или, при `ADDR → GND`, задайте `0x48`;
3. выберите канал `A0`, если `OUT` подключён к A0;
4. нажмите пресет **300 A** — стартовая чувствительность будет около **6.667 mV/A**;
5. сохраните настройки;
6. затем выполните двухточечную калибровку.

## Двухточечная калибровка

### 1. Ноль

Убедитесь, что ток через проводник равен нулю, затем нажмите **Калибровать ноль**. Прошивка усреднит несколько измерений ADS1115 и сохранит фактическое напряжение нуля в NVS. Для этого датчика ожидается значение около **2500 mV**.

### 2. Эталонный ток

Пропустите стабильный ток, измеренный проверенным амперметром/клещами, введите его значение **со знаком** и нажмите **Калибровать по току**. Прошивка вычислит чувствительность mV/A и направление автоматически.

Для лучшей точности желательно использовать ток не менее 10–20% диапазона датчика, то есть для версии 300 A желательно хотя бы порядка **30–60 A**, если это безопасно и доступно в вашей установке.

## Электробезопасность

PZCT-DC63 обеспечивает гальваническую развязку измеряемого силового проводника от электроники датчика, но это не отменяет требований к изоляции, сечению кабеля, предохранителям и безопасной работе с батарейными токами. Не разрывайте силовую цепь для измерения: провод проходит через окно датчика без электрического контакта с ним.
