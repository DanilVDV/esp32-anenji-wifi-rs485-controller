# PZCT-DC63 + ADS1115: измерение DC-тока

Прошивка v0.15.9 поддерживает опциональный датчик тока Холла **PZCT-DC63** через 16-битный АЦП **ADS1115** на общей I²C-шине ESP32 (`GPIO21 = SDA`, `GPIO22 = SCL`).

В этой сборке вся низковольтная периферия питается от **3.3 V**. ADS1115 и используемый модуль PZCT-DC63 подключаются к выводу `3V3` ESP32, земля общая.

> У PZCT-DC63 встречаются разные исполнения и платы-преобразователи. Используйте питание 3.3 V только для того варианта, для которого оно допустимо по маркировке/документации конкретного экземпляра. Если ваш модуль рассчитан только на 5 V, не подключайте его к 3.3 V «по аналогии».

## Подключение 3.3 V

На разных ESP32 DevKit GPIO могут быть подписаны по-разному. **Главный ориентир — номер GPIO**, а `D21`, `SDA`, `IO21` и т. п. — варианты шелкографии.

| ESP32 DevKit | GPIO | Маркировка на плате (типично) | ADS1115 / PZCT |
|---|---:|---|---|
| 3.3 V | — | **`3V3` / `3.3V`** | `VDD/VCC` обоих модулей |
| SDA | **21** | `SDA` / `D21` / `IO21` / `21` | ADS1115 `SDA` |
| SCL | **22** | `SCL` / `D22` / `IO22` / `22` | ADS1115 `SCL` |
| GND | — | **`GND`** | общий `GND` |
| — | — | — | PZCT `OUT` → ADS1115 `A0` (либо A1/A2/A3) |

```text
ESP32 DevKit                  ADS1115                    PZCT-DC63
-----------                   -------                    ---------
3V3 / 3.3V ------------------> VDD ---------------------> VCC
GND --------------------------> GND ---------------------> GND
GPIO21 / SDA / D21 ----------> SDA
GPIO22 / SCL / D22 ----------> SCL
                               A0 <----------------------- OUT
```

Поскольку ESP32 и ADS1115 находятся в одной 3.3-вольтовой логике, отдельный I²C level shifter в этой схеме не требуется. Калибровка прошивки использует фактическое напряжение ADS1115, поэтому точный ноль и чувствительность определяются уже на установленном датчике.

## Проводник через датчик

Через окно PZCT-DC63 пропускается **только один проводник** измеряемой DC-линии. Если пропустить одновременно плюс и минус одной цепи, их магнитные поля компенсируются и датчик покажет почти ноль.

Направление тока зависит от ориентации проводника в окне. Если знак получается обратным, можно либо развернуть датчик/проводник, либо включить `инвертировать направление` в Web UI.

## Настройка в Web UI

В карточке **PZCT-DC63 · DC ток / ADS1115**:

1. включите датчик;
2. оставьте адрес `Авто 0x48…0x4B` или задайте адрес вручную;
3. выберите канал A0–A3;
4. для быстрого старта выберите номинал 100/300/500 A;
5. сохраните настройки.

## Двухточечная калибровка

### 1. Ноль

Убедитесь, что ток через проводник равен нулю, затем нажмите **Калибровать ноль**. Прошивка усреднит несколько измерений ADS1115 и сохранит фактическое напряжение нуля в NVS.

### 2. Эталонный ток

Пропустите стабильный ток, измеренный проверенным амперметром/клещами, введите его значение **со знаком** и нажмите **Калибровать по току**. Прошивка вычислит чувствительность mV/A и направление автоматически.

Для лучшей точности желательно использовать ток не менее 10–20% диапазона датчика.

## Электробезопасность

PZCT-DC63 обеспечивает гальваническую развязку измеряемого силового проводника от электроники датчика, но это не отменяет требований к изоляции, сечению кабеля, предохранителям и безопасной работе с батарейными токами. Не разрывайте силовую цепь для измерения: провод проходит через окно датчика без электрического контакта с ним.
