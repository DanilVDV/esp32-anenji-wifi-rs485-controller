# Wiring / схема подключения

## 1. RS‑485

Прошивка использует UART2 ESP32:

| Сигнал | GPIO | Куда подключать |
|---|---:|---|
| RX2 | 16 | `RO` RS‑485 transceiver |
| TX2 | 17 | `DI` RS‑485 transceiver |
| Direction | 4 | объединённые `DE` и `/RE` |
| GND | — | общий GND |

Линии `A` и `B` трансивера идут на RS‑485 инвертора. PZEM‑016 может находиться на этой же half‑duplex шине.

```text
ESP32                    RS-485 transceiver                 ANENJI
-----                    ------------------                 ------
GPIO17 (TX2) ----------> DI
GPIO16 (RX2) <---------- RO
GPIO4          --------> DE + /RE
GND            --------> GND
                          A  ------------------------------> A
                          B  ------------------------------> B

                                                    + optional PZEM-016
                                                    | same A/B bus
```

### Что исходник НЕ определяет

Он не задаёт конкретную модель трансивера, его напряжение питания, наличие терминации/смещения и распиновку разъёма ANENJI. Эти параметры нельзя надёжно восстановить только из прошивки.

Рекомендации для физического слоя:

- используйте трансивер, безопасный для логики 3.3 В ESP32;
- общий GND обычно необходим, если нет гальванической развязки;
- терминация 120 Ω ставится по правилам конкретной RS‑485 топологии, а не «автоматически везде»;
- при отсутствии связи проверьте A/B и адреса устройств.

## 2. I²C

```text
ESP32 GPIO21 (SDA) ----+---- DS1307/DS3231 SDA
                       +---- AT24C32 SDA
ESP32 GPIO22 (SCL) ----+---- DS1307/DS3231 SCL
                       +---- AT24C32 SCL
GND -------------------+---- common GND
```

Параметры из кода:

- SDA = GPIO21;
- SCL = GPIO22;
- bus = 100 kHz;
- RTC = `0x68`;
- AT24C32 = scan `0x50..0x57`;
- I²C timeout = 50 ms.

## 3. BOOT

GPIO0 — штатная BOOT-кнопка многих ESP32 DevKit. Прошивка использует её также как сервисную кнопку:

- ~5 с → Setup AP;
- ~15 с → очистка Wi‑Fi config.

Учитывайте это при ручном входе в flashing mode.
