# Contributing

Перед PR:

- не добавляйте реальные Wi‑Fi/admin credentials;
- сохраняйте инвариант: UART2/RS‑485 принадлежит только RTU worker;
- любые новые write-регистры добавляйте осознанно в allow-list и документируйте диапазоны;
- проверяйте поведение offline/timeout, а не только happy path;
- при изменении EEPROM layout повышайте version и сохраняйте миграцию;
- обновляйте `README.md` и соответствующий файл в `docs/`.

Для изменений силовых/батарейных профилей в PR обязательно укажите модель инвертора, напряжение системы и источник допустимых значений.
